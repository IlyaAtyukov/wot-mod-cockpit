# Участие в проекте

WoT Mod Cockpit поддерживается одним человеком в свободное время и распространяется «как
есть»: без гарантий, сроков ответа и обязательств что-либо добавить. Сообщения об ошибках,
вопросы и предложения приветствуются — через Issues на GitHub.

## Сообщение об ошибке

Чтобы ошибку можно было воспроизвести, укажите:

- версию кокпита (коммит или релиз) и версию клиента игры (`paths.xml` → `mods\<версия>`);
- что делали, что ожидали и что получили;
- текст ошибки из строки состояния или окна, а если дело в моде — фрагмент `python.log`.

Перед отправкой уберите из текста и снимков личное: имя пользователя Windows в путях, ники,
идентификаторы аккаунта.

## Pull request

- **Тесты зелёные.** `dotnet build` без новых предупреждений и `dotnet test` без падений.
  Тесты, которым нужна ваша машина (`Env=RealMachine`), по умолчанию пропускаются; если
  изменение их касается, прогоните их у себя (см. [docs/testing.md](docs/testing.md)).
- **Новое поведение — с тестом**, который проверяет результат, а не факт вызова метода.
- **Core без WPF.** `WotModCockpit.Core` не ссылается на WPF; всё, что связано с окнами, живёт
  в `WotModCockpit.App`.
- **Одно изменение — один PR.** Пользовательские тексты — на русском.
- **Документация вместе с кодом.** Если меняются настройки, переменные окружения, имена
  кнопок или правила, поправьте `README.md` и `docs/*.md`. Снимки окон пересоздаются тестами
  (см. [docs/testing.md](docs/testing.md#снимки-окон-для-документации)), а не снимаются
  вручную с вашей машины.

## Чего не должно быть в репозитории

- **Ваших файлов игры и личных данных:** `modsettings.dat`, `python.log`, реплеев, конфигов
  из `mods\configs`, снимков экрана с путями вашего профиля.
- **Содержимого чужих модов** — ни распакованного, ни декомпилированного, ни в виде фикстур
  тестов. Для тестов пишите синтетические данные (`ru.example.*`, `foreign_pack`).
- **Декомпилированного кода клиента** — ни дерева исходников, ни отдельных файлов, ни
  крупных фрагментов. Дерево каждый извлекает у себя (см.
  [docs/client-sources.md](docs/client-sources.md)); рабочие каталоги `.scratch/` и `.tools/`
  уже в `.gitignore`.
- **Сторонних инструментов под GPL** (uncompyle6, xdis) в составе сборки.

Запросы и PR, цель которых — функции, запрещённые правилами игры (например, показ скрытой
от игрока информации или автоматизация игровых действий), не принимаются.

## Лицензия вклада

Присылая изменения, вы соглашаетесь, что они распространяются на условиях лицензий проекта:
MIT ([LICENSE](LICENSE)), а для кода, который кокпит вставляет в моды пользователей, —
дополнительно 0BSD ([LICENSE-0BSD](LICENSE-0BSD)).

## In English

The project is maintained by one person as is, with no guarantees of support or response
time. Issues are welcome. Pull requests must keep `dotnet build` free of new warnings and
`dotnet test` green. Never commit personal game files (`modsettings.dat`, `python.log`,
replays, configs), content of third-party mods, or decompiled client code: use synthetic
test data instead. Contributions are accepted under the project's licences (MIT, plus 0BSD
for code the cockpit inserts into users' mods).
