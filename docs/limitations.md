# Ограничения

[← к README](../README.md)

Что кокпит сознательно не делает и чего в нём пока нет.

## Границы инструмента

- **Не редактор кода.** Код мода пишется в VS Code (или где угодно). В каталог проекта
  кокпит пишет только по явной кнопке: `wotmod.json` («создать wotmod.json»), файлы
  дизайнера настроек («Записать в проект»), вставленный рецепт (с копией `.bak`), `<name>` и
  `<description>` в `src\meta.xml` (диалог «Имя и описание мода»), новый проект целиком
  (мастер «Новый мод…»).
- **Не запускает игру.** Процессы клиента опрашиваются только ради запрета: пока игра
  запущена, экран «Моды» ничего не меняет.
- **Не пишет в игру по своей инициативе.** Каталог игры — только чтение, пока не нажата
  кнопка. Запись бывает двух видов, и оба — по явному нажатию с подтверждением, где написан
  полный путь: сборку и деплой делает `build.py` (кокпит вызывает его с флагом), а операции
  экрана «Моды» (включить, выключить, поставить из `dist\`, удалить) кокпит выполняет сам —
  только внутри `mods\<версия>` и только над файлами `*.mtmod` и `*.mtmod.off`.
- **Нет формы для настроек самого кокпита.** `pythonExe`, `editorExe`, `pyrightPath`,
  `nodePath`, `modIdPrefix` и остальное правятся в `settings.json` руками (см.
  [Настройки](configuration.md)). Поиск Python кэшируется на время работы кокпита.
- **Нет кнопки «извлечь исходники текущего клиента».** Кокпит извлекает дерево только при
  переходе на новую версию клиента; первое дерево делается скриптом шаблона (см.
  [Исходники клиента](client-sources.md)).
- **Автосборки по сохранению нет.** Поле `autoBuildOnSave` в настройках зарезервировано,
  но не используется.

## Браузер API и preflight

- **Сигнатуры событий восстановлены не для всех имён** (на клиенте 1.44 — для 681 из 892).
  Не хватает тех, что возбуждаются через локальную переменную (`ctrl.onX(...)`).
- **Индекс символов и каталоги читают дерево независимо**, поэтому память процесса после
  прохода по всем панелям браузера заметно больше, чем у одного индекса.
- **Preflight не умеет исключать пути из анализа.** Вендорный код внутри мода (библиотеки,
  которые крупные моды возят с собой) даёт неустранимый шум `WOT002` и `WOT020`.
- **`WOT014` дублирует проверки `build.py`.** Два независимых источника истины с похожими
  формулировками; правильнее было бы спрашивать сам `build.py`.
- **Список нативных модулей движка в `ClientApiOracle` статический.** Новый нативный модуль
  в следующей версии клиента даст ложную ошибку `WOT002`, пока список не обновят.
- **У находок pyright пустое поле «как чинить»**: pyright его не отдаёт. Показывается общее
  объяснение про `typeCheckingMode=off` и разбор кода Python 2 правилами Python 3.

## Дизайнер настроек

- Нет отмены (Ctrl+Z), нет захвата клавиши «нажмите сочетание», нет подсловаря `button`.
- Поддержан только ModsSettingsAPI; другие API настроек — нет.
- Схема в центре экрана — приближение. Как блок мода выглядит в окне настроек в ангаре,
  видно только в игре.

Подробнее — в [Дизайнере настроек](settings-designer.md#чего-в-дизайнере-нет).

## Экран «Моды»

- **Массовых операций нет** — ни «выключить всё», ни выделения нескольких строк: в каталоге
  лежат чужие моды, и цена ошибки здесь выше цены удобства.
- **Россыпью в `res_mods` кокпит не управляет**: по ней есть только сводка.
- **Порядок загрузки (`load_order.xml`) не трогается.** Схема файла неизвестна, а ошибка в
  нём ударила бы по загрузке всех модов сразу.
- **Происхождение мода не определяется** (поставлен вручную или установщиком модпака).
- **Поведение установщиков модпаков по отношению к `.mtmod.off` не проверялось.** Пара
  `X.mtmod` + `X.mtmod.off` помечается флагом `HasStateTwin`, чтобы экран мог сказать, что
  выключенный мод снова включил кто-то другой.
- **«Все записи Stored» — определение одностороннее.** .NET не отдаёт метод сжатия записи
  ZIP публично, поэтому запись считается сжатой, если её сжатый и исходный размеры
  различаются. «Сжато» определяется точно, «Stored» — предположение.

## Игра и клиенты

Кокпит разрабатывался на клиентах «Мира танков» (Lesta) 1.44–1.46 под Windows. Поиск
установки знает и клиент Wargaming (World of Tanks), но работа с ним не проверялась.
