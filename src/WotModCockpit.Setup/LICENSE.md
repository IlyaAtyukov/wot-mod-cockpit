# Лицензия заглушки установщика

Заглушка установщика — весь код этой папки и значок
`../WotModCockpit.App/Resources/cockpit.ico`, который csproj встраивает в exe, —
дополнительно лицензирована по **0BSD** (`LICENSE-0BSD` в корне репозитория). Кокпит
дописывает к ней архив с модами, и
получившийся `Setup.exe` авторы модов раздают игрокам: никаких лицензионных приписок,
копирайтов или файлов рядом с ним для этого не требуется.

Сторонних библиотек в заглушке нет — только сборки .NET Framework, которые уже есть в
Windows.

Полный перечень того, что покрывает 0BSD, — в
[`../WotModCockpit.Core/Recipes/Recipes/LICENSE.md`](../WotModCockpit.Core/Recipes/Recipes/LICENSE.md).
